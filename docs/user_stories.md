# User Stories

1. **Dokumentum rögzítése:** Könyvtárosként új könyveket és folyóiratokat szeretnék felvenni a nyilvántartásba cím, ár és típus-specifikus adatok (szerző vagy évfolyam) megadásával.
2. **Hibás adatok kiszűrése:** Könyvtárosként azt szeretném, hogy a program megakadályozza az üres cím vagy negatív ár rögzítését.
3. **Listázás és rendezés:** Könyvtárosként meg szeretném tekinteni az összes tárolt dokumentumot, valamint ár vagy cím szerint rendezni őket.
4. **Adatok megőrzése:** Könyvtárosként azt szeretném, hogy a rögzített adatok kilépéskor mentésre kerüljenek, és a következő indításkor automatikusan visszatöltődjenek.
